# ControlPhone 3.0.1 — دليل العربية (Windows)

منصة Windows للتحكم بعدد كبير من هواتف Android في وقت واحد: عرض الشاشات مباشرة، التحكم الفردي والجماعي، أدوات ADB،
نقل الملفات، تثبيت التطبيقات، الاتصال عبر USB وWi-Fi وOTG/LAN، ومساعد ذكاء اصطناعي متعدد المزودين — بواجهة عربية
كاملة واتجاه RTL.

## 1. التثبيت

**الطريقة الأولى — المثبّت (مستحسن)**

1. نزّل `ControlPhone-Setup-v3.0.1-win64.exe` من صفحة الإصدارات (Releases).
2. شغّله. لا يحتاج صلاحيات مدير: يُثبَّت لحساب Windows الحالي في `%LOCALAPPDATA%\Programs\ControlPhone`.
3. المثبّت بواجهة إنجليزية وعربية (اتجاه RTL)، وينشئ اختصارات في قائمة ابدأ واختصار سطح المكتب (اختياري) ومدخلاً
   في «إلغاء تثبيت البرامج».
4. مجلد `data\` (أرقام الهواتف والأسماء والمجموعات والإعدادات ومزودو الذكاء الاصطناعي والمحادثات) **يبقى** بعد
   إلغاء التثبيت أو التحديث؛ لا يُحذف منه شيء.

التثبيت الصامت لأجهزة متعددة:

```bat
ControlPhone-Setup-v3.0.1-win64.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /DIR="D:\Tools\ControlPhone"
```

**الطريقة الثانية — النسخة المحمولة**

1. نزّل `ControlPhone-v3.0.1-win64.zip` من صفحة الإصدارات (Releases).
2. فُكّ الضغط في مجلد قابل للكتابة، مثل `C:\ControlPhone` (لا تشغّل البرنامج من داخل ملف ZIP).
3. شغّل `ControlPhone.exe`.

الحزمة مستقلة: تحتوي .NET Runtime و adb و FFmpeg و scrcpy-server — لا تحتاج إلى تثبيت أي شيء آخر. بعد التشغيل اختر
طريقة العمل: **التحكم بكل الأجهزة** (شبكة الشاشات + مزامنة المجموعات) أو **إظهار هاتف واحد فقط**.

## 2. توصيل الهواتف

- على الهاتف: خيارات المطوّر ← **تصحيح USB**.
- **USB**: يُكتشف الهاتف تلقائياً؛ اقبل رسالة «السماح بتصحيح USB» مرة واحدة (حدّد «السماح دائماً من هذا الكمبيوتر»).
- **Wi-Fi**: زر الفأرة الأيمن على الهاتف ← **USB ← Wi-Fi**، أو **الاتصال عبر Wi-Fi** بعنوان IP، أو **فحص الشبكة المحلية**.
- **Android 11+**: استخدم **الاقتران بالرمز** (التصحيح اللاسلكي ← اقتران الجهاز برمز).
- **OTG/LAN (مزارع الهواتف)**: من الإعدادات فعّل **وضع OTG/LAN**؛ يبحث البرنامج في شبكات الكمبيوتر المحلية عن هواتف
  لديها ADB عبر الشبكة ويتصل بها تلقائياً.

كل هاتف يحتفظ برقمه (`#1`, `#2`…) واسمه ومجموعاته بعد إعادة التشغيل (في `data\config.json`).

## 3. التحكم

- نقر: تحديد هاتف واحد · **Ctrl+نقر**: إضافة/إزالة من المجموعة · سحب مستطيل: تحديد عدة هواتف · **Ctrl+A**: الكل ·
  **Esc**: إلغاء التحديد.
- عند تحديد هاتفين أو أكثر تُطبَّق أي عملية على هاتف واحد على المجموعة كاملة (**F3** لإيقاف المزامنة مؤقتاً).
- الفأرة على الشاشة الصغيرة = إصبع (نقر، سحب، ضغط مطوّل). الزر الأوسط = الرئيسية، الزر الجانبي = رجوع،
  Shift+عجلة = تمرير، Alt+سحب = تكبير بإصبعين.
- اكتب على لوحة المفاتيح والمؤشر فوق الهاتف لإرسال النص إليه. **Ctrl+V** يلصق حافظة الكمبيوتر في كل الهواتف المحددة.
- القائمة اليمنى: تكبير، تثبيت APK، استيراد/تصدير ملفات، أوامر ADB، إعدادات الشبكة، إعادة التسمية/الترقيم،
  المجموعات، إيقاف/متابعة العرض، إعادة تشغيل، الدخول إلى Recovery (TWRP).

## 4. اللغة العربية وRTL

- الإعدادات ← **Ngôn ngữ / Language / اللغة** ← **العربية**. يُعاد تشغيل البرنامج مرة واحدة لتُبنى كل النوافذ بالاتجاه الجديد.
- تُحفظ اللغة وتُستعاد في كل تشغيل.
- الواجهة كلها تنعكس (يمين ← يسار): القوائم، الأزرار، الأشرطة، النوافذ، الرسائل، رسائل الخطأ.
- الحقول التقنية تبقى من اليسار إلى اليمين (الروابط، أوامر ADB، مفاتيح API، مسارات الملفات) حتى تظل الأرقام والأوامر مقروءة.
- الأرقام تُعرض بالأرقام الغربية لتوافق أرقام الهواتف وأوامر ADB.

## 5. مزودو الذكاء الاصطناعي

المزودون المدعومون: **Google Gemini**، **OpenAI**، **Anthropic Claude**، وأي خدمة متوافقة مع OpenAI
(OpenRouter، DeepSeek، Groq، Ollama المحلي، أو عنوان مخصص).

1. اضغط **AI** في الشريط الأعلى (أو ⋯ ← **مزودو الذكاء الاصطناعي…**).
2. **إضافة مزود** ← اختر نوع الخدمة ← املأ الاسم وعنوان API واسم النموذج ← ألصق مفتاح API.
3. **اختبار الاتصال** للتأكد، ثم **حفظ**.
4. **افتراضي** لتحديد المزود المستخدم في المحادثات الجديدة.
5. **جلب قائمة النماذج** يقرأ النماذج المتاحة من المزود (عند توفره).

### أمان المفاتيح

- كل مستخدم يدخل مفتاحه بنفسه؛ لا يوجد أي مفتاح داخل البرنامج أو في المستودع.
- يُشفَّر المفتاح محلياً بـ **Windows DPAPI** لحساب Windows الحالي ويُخزَّن في `data\ai\ai.json` فقط.
- نسخ الملف إلى جهاز أو حساب آخر لا يكشف المفتاح ولا يجعله صالحاً.
- لا تُكتب المفاتيح في السجلات، وتُحجب من رسائل الخطأ (`?key=…`، `Bearer …`، `sk-…`).
- لا يُرسل المفتاح إلا إلى المزود الذي اخترته، وفي الترويسة التي يطلبها.
- **حذف كل بيانات الذكاء الاصطناعي** يحذف المزودين والمفاتيح المشفّرة وسجل المحادثات نهائياً.

### إعدادات كل مزود

أقصى طول للرد (tokens)، درجة الاستجابة (temperature)، المهلة (ثانية)، اختبار الاتصال، جلب النماذج، آخر نجاح/آخر خطأ.

## 6. المساعد الذكي (تنفيذ حقيقي)

المساعد ليس واجهة محادثة منفصلة: إنه متصل بمحركات البرنامج عبر **24 أداة** تنفّذ وظائف حقيقية:

- قراءة: `list_devices`، `device_details`، `list_groups`، `get_settings`، `diagnostics`، `read_logs`، `app_guide`.
- تنظيم وعرض: `select_devices`، `assign_group`، `rename_device`، `stream_control`، `screenshot`، `connect_device`، `scan_lan`.
- تغيير الهواتف أو الإعدادات (تتطلب موافقتك): `device_action`، `send_text`، `open_url`، `app_control`،
  `install_apk`، `push_file`، `shell`، `set_setting`.

أمثلة:

- «أي الهواتف متصلة الآن؟ وما حالة البطارية؟»
- «لماذا الهاتف #2 غير متصل؟ افحص السجلات والتشخيص.»
- «أنشئ مجموعة باسم مختبر الاختبار من الهواتف المحددة.»
- «أوقف البث للهواتف المحددة لتخفيف الحمل.»
- «ثبّت التطبيق الموجود في C:\apps\test.apk على الهواتف المحددة.» (يطلب موافقة أولاً)

الضوابط:

- العمليات الحساسة تعرض أولاً الأدوات والهواتف المستهدفة والمعاملات، ثم تنتظر موافقتك.
- لا تُنفَّذ عملية على «كل الهواتف» إلا إذا طلبتها صراحة؛ الافتراضي هو الهواتف المحددة.
- لا يخترع المساعد حالة الهواتف؛ يقرأها أولاً بالأدوات.
- لا يطلب مفاتيح API ولا يعرضها.
- يمكنك إيقاف أي مهمة جارية بزر **Dừng / إيقاف**، والحد الأقصى 8 خطوات أدوات لكل طلب (قابل للتعديل 1–20).

### النسخ الاحتياطي والاستعادة (3.9)

قسم «الإعدادات ← تصدير/استيراد الإعدادات» صار يوفّر **«نسخ كل البيانات احتياطياً…»** و**«الاستعادة من نسخة احتياطية…»**.
ملف ZIP يضم أسماء الهواتف وأرقامها ومجموعاتها والإعدادات وتفضيلات الواجهة وسجل محادثات الذكاء الاصطناعي — **ولا يضم
مفاتيح API** (مشفّرة بـDPAPI لكل جهاز وتبقى عليه). الاستعادة تدمج لا تستبدل: تُطابَق الهواتف بالرقم التسلسلي، وتُوحَّد
المجموعات، ولا ينقص رقم الجهاز التالي، ولا تُلمس المحادثات الموجودة. وأي ملف ليس نسخة احتياطية لـControlPhone أو أتى من
إصدار أحدث يُرفض قبل كتابة أي شيء.

### عرض الإجابة تدريجياً (3.8)

عندما يدعم المزوّد البث (OpenAI وAnthropic وGemini وكل خدمة متوافقة مع OpenAI) تُعرض إجابة المساعد أثناء كتابتها بدل
الانتظار ثم الظهور دفعة واحدة. هذا تحسين عرض فقط: إذا فشل البث أو عاد فارغاً أو لم يدعمه المزوّد يُعاد الطلب بالطريقة
العادية، فلا يمكن لهذه الميزة أن تُفقد إجابة. يُفعَّل من «الذكاء الاصطناعي ← خيارات المساعد ← إظهار الإجابة تدريجياً».

### سجل مستقل لكل جهاز (3.7)

بالنقر الأيمن على أي هاتف ← «سجل الجهاز…» تظهر سجلّه الخاص: كل تغيّر حالة (`offline → connecting → online`،
`→ error · السبب`) ونتيجة كل عملية نُفِّذت عليه، الأحدث في الأسفل. أزرار «نسخ» و«فتح الملف» و«حذف السجل» تعمل فعلياً،
والملف في `data\logs\devices\<serial>.log` (256 كيلوبايت، يُدوَّر إلى `.log.1`) فيبقى بعد إغلاق التطبيق. والمساعد الذكي
يقرأ السجل نفسه بأداة `device_log` — اسأله «لماذا ينقطع الهاتف رقم 4؟» فيجيب من تاريخ الهاتف نفسه لا من التخمين.

### الوضع الآمن عند فشل بدء التشغيل (3.6)

إذا لم يكتمل بدء التشغيل مرتين متتاليتين، يبدأ التطبيق في **الوضع الآمن**: أخف ملف فيديو (240p/5 إطار في الشبكة،
640p/10 في العرض المكبَّر)، مع تجاهل إعدادات الهواتف الخاصة وعدم تفضيل المُرمِّز العتادي. لا يُكتب أي شيء في إعداداتك،
وإغلاق التطبيق وإعادة فتحه يعيد الوضع الطبيعي — فمشكلة تعريف كرت الشاشة لم تعد تحجب عنك النافذة.

### حزمة التشخيص (3.5)

من «روابطنا والدعم» ← «حزمة التشخيص» ← «تصدير حزمة التشخيص…» يُنشأ ملف ZIP واحد يمكن إرفاقه بالبريد أو إرساله في مجموعة
تيليجرام: الإصدارات (التطبيق، ويندوز، .NET، ADB، FFmpeg)، قائمة الهواتف (الأرقام والأسماء ونوع الاتصال وإصدار أندرويد —
بلا أرقام تسلسلية)، سجل العمليات، `crash.log`، وملفات الإعدادات. ملف `ai.json` مستبعَد كلياً، وكل ملف نصي يُنقّى من
`sk-…` و`AIza…` و`Bearer …` و`?key=` قبل الكتابة، فالحزمة آمنة لمشاركتها.

### إيقاف العمليات الجماعية (3.4)

كل عملية جماعية تظهر في بطاقة تقدّم؛ زر ⏹ على البطاقة (أو «إيقاف» في نافذة النتائج) يوقفها: الهواتف التي لم تبدأ بعد
تُتخطّى وتُعلَّم كموقوفة، والهاتف الذي يعمل الآن يُكمل أمره الحالي. النتائج تفصل ثلاث حالات (✓ نجح، ✗ فشل، ⏸ موقوف)،
وزر «تحديد الهواتف الفاشلة» لا يشمل الموقوفة.

### التحديثات (3.3)

من قائمة «⋯» ← «التحقق من التحديثات…» يقرأ التطبيق أحدث إصدار على GitHub ويعرض ما تغيّر وحجم الملفات مع زرّين:
فتح صفحة الإصدار أو تنزيل المثبّت. لا ينزّل التطبيق ولا يثبّت أي شيء تلقائياً، والفحص التلقائي يحدث مرة كل 24 ساعة
على الأكثر (يمكن إيقافه من «روابطنا والدعم»)، و«تجاهل هذا الإصدار» يُسكِت التنبيه حتى الإصدار التالي.

### حماية ملف الإعدادات

ملف `config.json` المعدَّل يدوياً أو التالف لم يعد يُفسد التشغيل: التطبيق يصحّح القيم خارج النطاق عند التحميل
(الإطارات، الدقة، معدل البت، حدود التوازي، منافذ LAN، السمة، الترتيب، اللغة) ويسجّل ما صُحّح في سجل العمليات، مع
الحفاظ على أسماء الهواتف وأرقامها.

## 8. الأداء والاستقرار

- شبكة الشاشات افتراضياً 480px · 15 إطاراً · 600 kbps لكل هاتف؛ يُفكّ ترميز البطاقات الظاهرة فقط.
- العرض الكبير (هاتف واحد) حتى 1280px · 30 إطاراً.
- «إيقاف العرض» يوقف البث ويُبقي التحكم.
- عند تكبير هاتف واحد يمكن إيقاف فك ترميز البقية (Focus viewer).
- إعدادات: حجم الشبكة/البِتريت/الإطارات، عدد الهواتف التي تبدأ البث معاً، عدد العمليات المتوازية،
  مُرمِّز برمجي عند فشل المرمّز العتادي.

## 9. حل المشكلات

| العَرَض | الحل |
|---|---|
| الهاتف «غير مصرّح» | افتح قفل الهاتف واقبل «السماح بتصحيح USB» مع «السماح دائماً». |
| الهاتف غير ظاهر | تحقّق من الكابل/المنفذ؛ قد يكون برنامج ADB آخر يحتجز الهاتف (يعرض الشريط الأعلى زر التحرير). |
| بطاقة سوداء | قد تكون الشاشة مطفأة؛ الهاتف ما زال قابلاً للتحكم. |
| «تعذّر تشغيل scrcpy» | جرّب الإعدادات ← المرمّز البرمجي، وافحص `data\logs`. |
| أداء منخفض مع هواتف كثيرة | خفّض جودة الشبكة أو استخدم «إظهار الهواتف المحددة فقط». |
| فشل مزود الذكاء الاصطناعي | افتح إعدادات المزود ← **اختبار الاتصال** واقرأ الرسالة (401 مفتاح، 404 نموذج، 429 حد استخدام). |

## 10. التحقق من البناء

شغّل `ControlPhone.exe --selfcheck` في الطرفية: يفحص الترجمة وRTL، تشفير DPAPI، تخزين المزودين، بروتوكولات
المزودين الثلاثة، سجل الأدوات، وبيانات الدعم، ويطبع PASS/FAIL ويعيد رمز خطأ عند الفشل. سير عمل GitHub يشغّل
الفحص نفسه على Windows قبل نشر الإصدار.
